# amazon-spendings-cockpit

## Usage
- Go to https://www.amazon.com/hz/privacy-central/data-requests/preview.html
- Submit a request for `Your Orders` export
- Download and extract the export file `Your Orders.zip`
- Find to the order history file `Your Orders/Your Amazon Orders/Order History.csv`
- Open https://qoomon.github.io/amazon-spendings-cockpit/
- Upload the order history file
